# What Are Best Practices for Progress Indication on Forms, Registration, and Setup?

## Progress indication
Progress indication is a way to show users how far they are in a process. It can be used in forms, registration, and setup processes. The goal is to help users understand where they are in the process and how much they need to do.

For example, you can use a progress indicator bar to show users what is left to do when filling out forms. You don't want to create a situation where the user needs to fill out a lengthy form and they don't know how many more steps they need to complete.

When designing a progress indication section, there are a few best practices to keep in mind. The first consideration is to keep it simple. The second consideration is to make it possible to go back to previous steps. Another consideration is to make the progress indiciation easy to find. And the last is to have clear section titles, percentages, or steps.

# What Are Best Practices for Designing Shopping Carts?

## Visibility
The first design consideration is making sure the shopping cart is visible to users at all times. most shopping cart designs will have the cart displayed in the upper right hand corner of the page. users should see the number of items in their cart displayed in the upper right hand corner of the page.

Another consideration is providing a clear way for users to update the quantity of items in their cart. Also a remove button next to each item in the cart. Another consideration is the shopping cart icon itself. The icon should be easily recognizable for all users. Finally you should provide a clear call-to-action button for the checkout.

# What is Progressive Disclosure

## Progressive Disclosure
Progressive Disclosure is a design pattern used to only show users relevant content based on their current activity and hide the rest. This is done to reduce cognitive load and make the user experience more intuitive. 

For instance, when you use Google's search page, most of your searches will be simple. So having a simple user interaface with very few options make sense. but for the few times you will need a more advanced search, Google provides an advanced search option that will reveal more options.

Another example of progressive disclosure would be the "more details" button on products in an e-commerce website. When you visit a site like Amazon, you will see a list of product images in different catgeories.

There are some important considerations when designing progressive disclosures. The first is to keep all important information visible at all times. Anotehr is to provide a single access point to access additional features or information. 

# What Is Deferred and Lazy Registration?

## Lazy Registration
Lazy registration is a UI design pattern that allows users to browse and interact with your application without having to register. A good example of this would be an e-commerce site. users should be able to browse through the products and add a few items to their cart. Then, if they are interested in purchasing, they will need to register.

# What Are Design Briefs and How Do Developers Work with Them?

## Design Briefs
A design brief is a document that outlines the objectives, goals, and requirements of a project. it is a roadmap that guides the design process and ensures that the final product meets the needs of the client.

Usually the client will write the design brief and it will serve as a working draft. Sometimes, the designer might write one and consult with the client to make sure it meets their needs.

There are a few key elements that should be included in the designer brief.

The first is the overview of the project and buisness. This overview should include the company's details, mission, values, unique selling points, and products or services.

The next key element should be to document the goals and objectives for the project. this should include the purpose of the project, and the desired outcomes.

Examples of goals include increasing traffic to a site or increasing the number of monthly page visits by X percent.

Another key element would be the target audience. The design brief should include information about the target demmographics, interests, and needs of the audience. 

Another key element would be the project scope. This should inlude deliverables, timeline, and budget. The deliverables should include a list of all the items that will be produced as part of the project, such as mockups and final designs.

One of the challenging aspects about project design is the timescale and budget. It is important to be realistic about what can be achieved within the given timeframe and budget. So, having a design brief that oultines constraints is important. 

# hat Are Some Common Tools Developers Should Know About That Are Used by Designers in the Industry?

## Common Design tools

Most of these design tools excel in vector-based design and prototyping.

Vector-based design involves creating digital art using mathematical formulas to define lines, shapes, and colors. Prototyping on the other hand, refers to the process of creating an interactive model of a product or user interface.

Let's talk about some common design tools developers should know about.

### Figma
Figma is one of the most ocmmon and essential design tools that developers should know. This could-based tool specializes in User Interface and User Experience (UI/UX) design. It enables design and development teams to collaborate from anywehere, offering built-in features such as:
- Vector-based design
- Automatic layout
- Commenting and feedback system
- Version history
- Real-time collaboration
- Design system, and more.

To get started with Figma, you can use the web-based interface or download the desktop app from your computer. It has a generous free tier, so you can get a lot done without paying for the pro version.

### Sketch
Sketch is another essential design tool that developers should be familiar with. Like Figma, it is vector-based and primarily used for UI/UX design.

Sketch is popular for its intuitive interface and simplicity, making it ideal for developers who want to quickly create prototypes. it's also widely used by designers for tasks like creating UIs, icons, and web layouts. 

The main constraints with Sketch are its lack of cloud-based interface and its availability only on MacOS.

### Adobe XD
Adobe XD is another Vector-based design and prototyping for UI/UX design, known for its seamless integration with other Adobe apps like Photoshop, Illustrator, and After Effects.

This integration makes workflows such as interactive prototyping and animations more efficient.

Adobe XD is available for both Windows and macOS and includes a cloud-based interface. For the best experience, however, you should use the app directly.

### Canva
Another design tool worth mentioning is Canva. You can use Canva to create a wide range of visual content, including posers, cover photos, presentations, short videos, and more. Its user-friendly and simple design makes it ideal for beginners.
